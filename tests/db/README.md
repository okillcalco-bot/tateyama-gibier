# 実DBテスト（請求書ステージング）

## 実行方法

`invoice_staging.test.sql` の**ファイル全体**を Supabase SQL Editor（または MCP の execute_sql）に
貼り付けて実行する。全体が `begin` 〜 `rollback` で囲まれているため、

- テストデータ（顧客・取込・明細・対応表）は**一切本番に残らない**
- スタッフキーもトランザクション内で一時キーに差し替えられ、rollbackで元に戻る

期待結果: 結果表の全行が `ok = true`。
