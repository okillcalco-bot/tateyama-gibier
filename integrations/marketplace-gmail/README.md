# 通販の注文メールの自動取り込み（さとふる・まいぷれ・AWAWA）

注文メールが届くと、業務アプリの **出荷処理タブ →「🛍 通販の注文」** に自動で載ります。
「📦 出荷した」を押すと、加工品の棚の在庫から引きます。

## しくみ

```
Gmail（沖さんのアカウント）
  └ Google Apps Script（Code.gs・15分ごと）
       商品・数・集荷日・伝票番号・金額だけを読み取る
       （AWAWA の届け先・購入者の名前・住所・電話は読み取らない）
  └ Supabase の marketplace_orders に入れる（同じメールは二度入らない）
業務アプリ（index.html 出荷処理タブ）
  └ 未出荷の一覧 →「出荷した」→ products の在庫を引き、product_movements に記録
```

| 通販 | 送り主 | 取り込む件名 |
|---|---|---|
| さとふる | info@satofull.co.jp | 「お礼品のお申込み」 |
| まいぷれのご当地ギフト | mypl-gift@jimo.co.jp | 「【出荷依頼】」 |
| AWAWA! FOOD | account@fb-awa.com | 「商品注文のお知らせ」（返信の「Re:」は除く） |

## 初回の設定（沖さんが1回だけ）

1. https://script.google.com を開き「新しいプロジェクト」→ 名前を「館山ジビエ 通販取込」にする
2. 最初からある `コード.gs` の中身を消して、このフォルダの `Code.gs` を丸ごと貼り付けて保存
3. 左の歯車「プロジェクトの設定」→ いちばん下の「スクリプト プロパティ」に2つ追加
   - `SUPABASE_URL` … 業務アプリと同じ Supabase の URL
   - `SUPABASE_ANON_KEY` … 業務アプリと同じ公開キー（anon）
   （キーはチャットに貼らず、ここに直接入れてください）
4. 上の関数の選択で `installTrigger` を選んで「実行」
   - 「承認が必要です」→ 自分のアカウントを選び、Gmail の読み取りと外部への送信を「許可」
   - これで15分ごとの自動実行が入り、直近3週間の注文メールがすぐ取り込まれます
5. 業務アプリの出荷処理タブで「🛍 通販の注文」に載っていることを確かめる

止めたいとき: Apps Script の左の時計「トリガー」から `importMarketplaceOrders` を削除。

## 在庫の対応（初回だけ商品ごとに決める）

通販の商品（セット）1つで、加工品の棚から何を何袋使うかを決めます。
出荷処理タブの注文の「🔗 在庫の対応」から選んで保存すると、同じ商品の注文すべてに使われます。

- まいぷれ「館山ジビエ2種セット」= 味付け肉 塩ニンニク 250g ×1 ＋ 味付けミンチ 山さんが 210g ×1（設定済み）
- さとふる「館山ジビエ 満足セット 猪肉 計1kg(4種)」= 中身を決めてください
- AWAWA の商品（ブロック・スライス・味付け肉）= 初めての注文のときに決めてください

## 失敗したとき

- メールの形式が変わって読めないときは「（読み取れませんでした）」の行として載ります（黙って捨てません）
- 送れなかったときは Apps Script の実行ログに出て、Google からエラーのメールが届きます
