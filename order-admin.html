顧客の価格・いつもの

取り込んだ請求書を確認して、顧客と商品を対応づけ、金額を検算してから購入実績へ反映します。 OCR・抽出結果はそのままでは実績になりません。スタッフが最終確認したものだけ反映されます。取込・反映はスタッフキーが必要です。
※ 担当者名はスタッフキー利用者による自己申告の操作名です。Supabase Auth 移行までは認証済み本人を証明するものではありません（移行後は本人IDに結びつけます）。

スタッフキーの変更

変更には管理者用回復コードが必要です（通常のスタッフキーでは変更できません）。 変更すると全端末で再入力が必要になり、操作は監査ログに残ります。
回復コードを紛失した場合の再設定は Supabase の SQL Editor から行います（手順は docs/order-site-plan.md）。
